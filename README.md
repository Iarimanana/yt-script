# yt-script

Get the script (transcript) of a YouTube video. You give it a channel and either
how many of its latest videos you want, or the title of one video.

```
$ yt-script https://www.youtube.com/@KarstenRunquist --title "Resident Evil: How To Adapt a Video Game in 2026"
Looking up https://www.youtube.com/@KarstenRunquist…
Fetching the transcript of 'Resident Evil: How To Adapt a Video Game in 2026' (https://www.youtube.com/watch?v=…)…
Title: Resident Evil: How To Adapt a Video Game in 2026
URL: https://www.youtube.com/watch?v=…
Transcript: English (auto-generated)

<the script, in paragraphs>
```

## Install

Needs Python 3.9 or newer.

```
git clone https://github.com/Iarimanana/yt-script.git
cd yt-script
pip install .
```

This installs the `yt-script` command. You can also run it without installing
the command: `pip install -r requirements.txt`, then `python -m yt_script …`.

## Usage

```
yt-script CHANNEL [--latest N | --title "TITLE"] [options]
```

`CHANNEL` can be any of:

- a channel link: `https://www.youtube.com/@KarstenRunquist` (a link to one of its
  tabs, like `…/@KarstenRunquist/videos`, works too)
- a handle: `@KarstenRunquist` or `KarstenRunquist`
- a channel ID: `UC…`
- the channel's name: `"Karsten Runquist"` (the first channel YouTube finds for it)

Pick the video with one of:

| Option | What you get |
| --- | --- |
| *(nothing)* | the latest video |
| `-n N`, `--latest N` | the N latest videos, newest first |
| `-t "TITLE"`, `--title "TITLE"` | the video with that title |

The title doesn't have to be exact: case, punctuation and accents are ignored, and
part of a title is enough ("How To Adapt a Video Game"). If no title is close
enough, it lists the closest ones it found.

Run `yt-script` with no arguments and it asks for the channel, then for a title or
a number of latest videos.

### Examples

```
# The latest video
yt-script @KarstenRunquist

# The 5 latest videos, each saved to its own file in ./scripts
yt-script @KarstenRunquist --latest 5 --output-dir scripts

# One video by title, with a timestamp before each paragraph
yt-script @KarstenRunquist --title "Resident Evil: How To Adapt a Video Game in 2026" --timestamps

# Spanish transcript if there is one, otherwise English, as JSON
yt-script @SomeChannel --lang es --lang en --format json
```

### Options

| Option | Description |
| --- | --- |
| `-l CODE`, `--lang CODE` | Preferred transcript language (default `en`). Repeat it for fallbacks. If the video has none of them, you get the transcript it does have, in its own language. |
| `--timestamps` | Start each paragraph with its `[m:ss]` time in the video. |
| `--keep-cues` | Keep sound cues like `[Music]` and `[Applause]` (dropped by default). |
| `-f json`, `--format json` | Print JSON (title, URL, language, the script, and timed paragraphs) instead of text. |
| `-o DIR`, `--output-dir DIR` | Save each script to `DIR/<title> [<video id>].txt` (or `.json`) instead of printing it. |
| `--search-depth N` | How many recent videos to look through when the channel's own search doesn't find `--title` (default 500). |
| `--proxy URL` | Send all requests to YouTube through this proxy (see below). |

Progress messages and errors go to stderr, and the script goes to stdout, so
`yt-script @KarstenRunquist > script.txt` saves just the script. The command exits
with status 1 if any video couldn't be fetched; the others are still printed.

## Use it from Python

```python
from yt_script import resolve_channel, find_video, latest_videos, fetch_transcript, to_paragraphs, format_script

channel = resolve_channel("https://www.youtube.com/@KarstenRunquist")
video = find_video(channel, "Resident Evil: How To Adapt a Video Game in 2026")
transcript = fetch_transcript(video.id, ["en"])
print(format_script(to_paragraphs(transcript.lines)))
```

## Good to know

- **The script is YouTube's captions.** A video's script is only available if it
  has captions, either written by the creator or auto-generated by YouTube. Creator
  captions are used when they exist. Auto-generated ones often have little
  punctuation, so paragraphs are split by time instead.
- **"Latest" means regular uploads**, as shown on the channel's Videos tab. Shorts
  and live streams aren't included.
- **YouTube blocks many cloud servers.** On a home connection it just works. If you
  run it on a cloud server (AWS, Google Cloud, …) and get "Request blocked" or "Sign
  in to confirm you're not a bot" errors, use `--proxy` with a residential proxy.
- Only use transcripts in ways the video's creator and YouTube's terms allow.

## How it works

[yt-dlp](https://github.com/yt-dlp/yt-dlp) reads the channel's video list and
search results (no video is downloaded), and
[youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api) fetches
the captions.
